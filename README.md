### Rekker OPS
*Internal operations platform for a Kenyan distribution business*

Built for ~20 active users across 4 roles: tracking LPOs, catching invoicing variances, logging GPS-verified merchandiser attendance, and generating PDF/CSV reports. Packaged as a PWA so field teams can use it on mobile without installation friction. Now being evolved into a multi-tenant B2B SaaS product.

`Node.js` `React` `MongoDB` `Express` `PWA` `PDF Generation` `GPS Verification`

### ICT Algorithmic Trading Engine
*Systematic XAUUSD trading bot built on Inner Circle Trader methodology*

A three-state machine (SCANNING → ARMED → IN_TRADE) that trades based on H4 market structure bias, liquidity sweep detection, Fair Value Gap and Order Block entries, and London/NY kill zone timing. Filters news events via Forex Factory, integrates Claude AI for sentiment, and enforces strict risk rules: 1% per trade, 5% daily loss limit, ATR-based circuit breakers, minimum 2:1 RR.

`Python` `MetaTrader 5` `ICT/SMC` `Algorithmic Trading` `Risk Management`

### DebtMS — Debt Management System

Centralized debt recovery system with client management, debt tracking, payment scheduling, and communication history. Built with a deliberate financial-grade design system: tabular number rendering, PAR bar components, and a layout that treats data as the product.

`React` `Node.js` `MongoDB` `Financial UI Design`

Built for the Office of the Auditor General Kenya, with architecture designed to extend to other East African public sector institutions via tenant isolation and subdomain routing. Focused on structured learning paths, content management, and institutional reporting.
