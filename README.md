### 📈 ICT Algorithmic Trading Engine
*Systematic XAUUSD trading bot built on Inner Circle Trader methodology*

A three-state machine (SCANNING → ARMED → IN_TRADE) that trades based on H4 market structure bias, liquidity sweep detection, Fair Value Gap and Order Block entries, and London/NY kill zone timing. Filters Forex Factory news events, integrates AI sentiment analysis, and enforces strict risk rules: 1% per trade, 5% daily loss limit, ATR circuit breakers, minimum 2:1 RR.

`Python` `MetaTrader 5` `ICT/SMC` `Algorithmic Trading` `Risk Management`
